TOPMed data in BDC combines whole-genome sequencing and other omics data with rich clinical, behavioral, imaging, environmental, and molecular data from studies spanning heart, lung, blood, and sleep research. BDC provides secure access to these data alongside scalable analysis tools and workflows, and hosts TOPMed Exchange Area (EA) data for TOPMed investigators with approved access. [Contact BDC](/help/contact-bdc) if you are interested in accessing EA data in BDC.

*For genotype imputation using the TOPMed reference panel, refer to the [TOPMed Imputation Server](https://imputation.biodatacatalyst.nhlbi.nih.gov/).*
